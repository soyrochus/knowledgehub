# Fixture walkthrough

From a KnowledgeHub-only checkout, build the current knowledgehub-model binary.
Read examples/fixtures/README.md, then use examples/fixtures/run.py with a fresh
run-id for unrelated-design or memento. The fixtures retain plans and explicit
gaps; a replay proves deterministic tooling, not fresh agent interpretation.
For an independent skill exercise, start with only the unrelated source files
and create a new plan, coverage expectations and private run. Do not copy the
maintained model-plan. Require source/native readback before reporting outcome.

Failure exercises: an existing destination must be preserved; a changed source
or plan must be refused on resume; use resolve under current authority after
response loss. Missing coverage must stay incomplete even with a structurally
complete model. Source conflicts stay unresolved until actually reviewed.
