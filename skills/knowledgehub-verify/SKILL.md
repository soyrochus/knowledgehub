---
name: knowledgehub-verify
description: Independently verify a persisted native KnowledgeHub baseline against retained source, mapping and query manifests, including exact originals, bounded coverage and original operation receipts.
---

Read [the native verification contract](references/model-authoring.md). Require
an explicit Hub directory, retained generation workspace and current host actor/
policy. Use the matching local knowledgehub-model binary; unavailable execution
is a prerequisite failure. No Modelarium, service or original chat is required.

Run resolve under current authority, then verify in a fresh process. Inspect
generation-manifest, source-manifest, exact plan/coverage, key-map and verification
reports. Check the native named baseline, original bytes/digests, resolving source
anchors, exact schema tokens and independently expected semantic IDs/properties/
assertions. Read consequential UI states, controls, effects and source artifacts;
aggregate counts or uploaded documents alone do not establish full coverage.

Consume every relevant continuation within finite documented limits. Treat
truncation, omitted in-scope semantics, unknown sources, unsupported extraction,
unresolved authority conflicts and denied/uncertain operation lookup as explicit
limits/failures. Never turn denial into absence, regenerate original operations,
repair backend files or reset a destination. Reconcile only known original IDs;
the generation manifest does not enumerate arbitrary native history.

Compare expected source obligations with persisted native content independently
of the generating agent's claims. Retain original/derived media distinctions,
interpretation status, permitted structural gaps and planned realization. No
stored rules, scripts, timers, provider actions or target workflows execute.

Return exact directory/scope/head/baseline, reproducible command/report paths and
known receipts. State source coverage, native validity/completeness,
interpretation review, implementation evidence and human acceptance separately.
An unreviewed interpretation stays unreviewed even when technical checks pass.
